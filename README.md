# 🗂 File Organizer

CLI-утилита на Python, которая автоматически сортирует файлы в папке по категориям — изображения, документы, видео, архивы и другие.

## Возможности

- 📂 Автоматическая сортировка файлов по типу (расширению)
- 👀 Preview mode — показывает план перемещений перед реальными изменениями
- 🛡 Защита от конфликтов имён — не перезаписывает существующие файлы
- ↩️ Undo — отмена последней организации
- 📝 Логирование всех операций в `organizer.log`
- ⚙️ Гибкая настройка категорий через `config.json`
- 🚫 Игнорирование служебных файлов (`.DS_Store`, временные файлы Word и т.д.)

## Установка

Требуется Python 3.9+. Дополнительных зависимостей нет — используются только стандартные библиотеки.

```bash
git clone <https://github.com/Andrey22223/file-organizer>
cd file-organizer
```

## Использование

Показать план перемещений без реальных изменений:
```bash
python main.py ~/Downloads --preview
```

Организовать папку:
```bash
python main.py ~/Downloads
```

Отменить последнюю организацию:
```bash
python main.py --undo
```

## Настройка категорий

Категории и расширения задаются в `config.json`:

```json
{
  "categories": {
    "Images": [".jpg", ".png"],
    "Documents": [".pdf", ".docx"]
  },
  "exclude": [".DS_Store", "~$*"]
}
```

Добавь свою категорию или расширение — правила подхватятся автоматически, без изменений в коде.
